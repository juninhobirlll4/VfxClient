Como instalar

O jeito mais fácil é o instalador: ele baixa o Minecraft, o Java e o VfxClient sozinho.

Baixe e instale

Clique em Baixar para Windows e rode o instalador (não pede administrador).

Entre na sua conta

Na aba Conta, entre com Microsoft ou crie uma conta offline (para servidores não-premium).

Clique em INICIAR

Na primeira vez o launcher baixa uns 300 MB e escolhe o melhor preset de FPS para o seu PC.

Personalize

Dentro do jogo, aperte Right Shift. Prefere instalar só o mod? Use o .jar com o Legacy Fabric 1.8.9.

Login Microsoft depende de aprovação da Mojang para o nosso aplicativo; até lá, use conta offline.
