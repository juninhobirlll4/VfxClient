VfxClient - Instruções
======================

Client de Minecraft 1.8.9 (mod + launcher) feito por nós. Este arquivo explica como
buildar, instalar, rodar e testar tudo.


1. O QUE É O QUÊ
----------------
core/       Mod "vfxcore" (Legacy Fabric, Java 8): HUD, menu (Right Shift), otimizações,
            utilidades, perfis de configuração, skin local.
launcher/   Launcher (Java 21 + JavaFX): contas, perfis, download do jogo, RAM, diagnóstico,
            atualização. Leva o mod embutido.
installer/  Script do Inno Setup e build-installer.ps1 (gera o .exe instalador).
site/       Página de download (GitHub Pages).
branding/   Logo (SVG fonte + PNG/ICO gerados) e paleta.

Organização do launcher (launcher/src/main/java/com/vfxclient/launcher/):
  auth/          contas Microsoft (código de dispositivo) e offline, skin e capa
  profiles/      perfis de jogo (versão, RAM, preset)
  settings/      configurações do launcher e informações do sistema
  mods/          instalação do vfxcore e da skin local
  game/          downloads (versão, bibliotecas, assets, Java, Legacy Fabric) e início do jogo
  optimization/  diagnóstico, limpeza de cache e argumentos da JVM
  updater/       atualização automática pelo GitHub Releases
  ui/            telas (Início, Conta, Configurações)
  cli/           modo linha de comando

Organização do mod (core/src/main/java/com/vfxclient/core/):
  module/        módulos (general, hud, util, visual, performance) e opções (setting/)
  hud/           desenho da HUD e contador de cliques
  gui/           menu (Click GUI), editor de HUD, seletor de cor, tema e as telas do jogo
                 (inicial, pausa, servidores; VanillaStyle = visual das telas de Opções)
  gui/font/      fontes Montserrat e Inter desenhadas em textura (GlyphAtlas)
  config/        perfis de configuração em JSON
  optimization/  leitura do hardware para os presets
  mixin/         ganchos no Minecraft


2. REQUISITOS (para desenvolver)
--------------------------------
- JDK 21 (Eclipse Temurin). JAVA_HOME apontando para ele.
- Git.
- Inno Setup 6, só para gerar o instalador:  winget install JRSoftware.InnoSetup
- Internet na primeira vez (o Gradle baixa o Minecraft e as dependências).

Não precisa instalar Java 8: para jogar, o launcher baixa o Java oficial da Mojang.


3. RODAR EM MODO DESENVOLVIMENTO
--------------------------------
Na pasta do repositório (cmd):

  gradlew build                 compila tudo (mod + launcher)
  gradlew :launcher:run         abre o launcher
  gradlew :core:runClient       abre o Minecraft de desenvolvimento só com o mod

Modo linha de comando do launcher (útil para testar):

  gradlew :launcher:run --args="--cli launch --offline SeuNick --wait"
  gradlew :launcher:run --args="--cli launch --offline SeuNick --join localhost:25565"
  gradlew :launcher:run --args="--cli launch --profile forge-1.8.9 --offline SeuNick"
  gradlew :launcher:run --args="--cli diagnose"
  gradlew :launcher:run --args="--cli clean-cache"
  gradlew :launcher:run --args="--cli versions"

Depois de instalado, os mesmos comandos funcionam com o executável:
  "%LOCALAPPDATA%\Programs\VfxClient\VfxClient.exe" --cli launch --offline SeuNick

Prints de teste sem mexer no teclado e no mouse (o jogo salva o print em screenshots\ e fecha
sozinho; não traga a janela do jogo para frente):
  gradlew :launcher:run -Dvfx.titleShot=true --args="--cli launch --offline Teste"
      tela inicial (vfx-teste-inicio.png); troque true por servidores, opcoes, video ou controles
  gradlew :launcher:run -Dvfx.openMenu=pausa --args="--cli launch --offline Teste --join localhost:25565"
      menu de pausa num servidor (vfx-teste.png); troque pausa pelo id de um módulo para ver as
      opções dele no menu
Testar com uma pasta de dados separada (não mexe na sua instalação):
  gradlew :launcher:run -Dvfx.home=C:\temp\vfx-teste


4. GERAR O INSTALADOR .EXE
--------------------------
  powershell -ExecutionPolicy Bypass -File installer\build-installer.ps1

Se houver OptiFine_1.8.9_*.jar em installer\local\ (ou na Área de Trabalho), ele entra no
instalador e no zip (só para mandar aos amigos; não suba esses arquivos no GitHub).
Sem OptiFine:  powershell -ExecutionPolicy Bypass -File installer\build-installer.ps1 -SemOptiFine

Gera em dist\:
  VfxClient-Setup-<versão>.exe     instalador (instala por usuário, sem pedir administrador)
  VfxClient-<versão>-portable.zip  versão portátil (extraia e abra VfxClient.exe)
  vfxcore-<versão>.jar             só o mod

Como funciona: o Gradle compila, o jpackage cria launcher\build\jpackage\VfxClient\
(VfxClient.exe + Java 21 embutido) e o Inno Setup empacota tudo num instalador.

Versão nova pela CI (jeito fácil): suba client_version em gradle.properties, escreva as
novidades em launcher\src\main\resources\com\vfxclient\launcher\changelog.txt, faça o commit
e dê git push. O GitHub Actions gera o instalador e publica a release sozinho (sem tag).
O launcher de quem já instalou confere o GitHub ao abrir e a cada 30 minutos e mostra
"Versão X disponível" com "Atualizar agora" (baixa, instala e reabre sozinho) ou "Mais tarde".
O repositório precisa ser público para essa checagem funcionar.


5. INSTALAR E JOGAR (usuário final)
-----------------------------------
1. Rode VfxClient-Setup-<versão>.exe.
2. Abra o VfxClient pelo atalho.
3. Aba Conta: entre com Microsoft ou crie uma conta offline.
4. Aba Início: escolha o perfil "VfxClient · 1.8.9" e clique em INICIAR.
   Na primeira vez ele baixa uns 300 MB (Minecraft, Java 8, Legacy Fabric).
5. No jogo, aperte Right Shift para abrir o menu do VfxClient.


6. PASTAS GERADAS
-----------------
%APPDATA%\.vfxclient\
  launcher\     settings.json, profiles.json, accounts.json, skins\, lista de versões
  versions\     JSON e jar de cada versão, natives\ (recriado a cada início)
  libraries\    bibliotecas do Minecraft e do Legacy Fabric
  assets\       sons, idiomas
  runtime\      Javas oficiais da Mojang (jre-legacy = Java 8)
  instances\<perfil>\     pasta do jogo de cada perfil:
      mods\vfxcore-<versão>.jar
      vfxclient\config\profiles\<nome>.json   opções do VfxClient (perfil de config)
      vfxclient\config\active-profile.txt
      vfxclient\skins\skin.png                skin local (conta offline)
      logs\launcher-output.log                saída do jogo
  cache\        downloads temporários

%LOCALAPPDATA%\Programs\VfxClient\   o launcher instalado


7. COMO TESTAR CADA FUNCIONALIDADE
----------------------------------
Launcher
- Versões: Início > "+ Outra versão" cria um perfil de Minecraft oficial (qualquer
  release). Escolha no seletor e clique INICIAR.
- Progresso: a barra mostra "Verificando...", "Bibliotecas", "Assets", "Java", "Iniciando".
  Na segunda vez tudo aparece como "Tudo em dia" e abre rápido.
- Status do jogo: "Jogo aberto" enquanto joga; ao fechar, "O jogo foi fechado" ou, se
  travar, "fechou com erro" e o botão "Ver log do jogo".
- RAM: Configurações > Memória RAM (slider ou campo). O texto mostra o total do PC e o
  recomendado. Salve o perfil; o valor vai para -Xmx no próximo início.
- Diagnóstico: Início mostra núcleos, RAM, placa de vídeo, avisos e o preset recomendado.
- Preset: Configurações > Preset de desempenho. "Automático" usa o recomendado do
  diagnóstico; no jogo, Desempenho > Preset de FPS mostra o que foi aplicado.
- Cache: Configurações > Limpar cache (mostra quantos MB liberou).
- Atualização: com uma release mais nova no GitHub, aparece a faixa "Nova versão".

Loaders do 1.8.9 (VfxClient / OptiFine / Forge)
- Tela Início (v0.8, minimalista): botão JOGAR, seletor de versão ao lado e "+" para outra
  versão do Minecraft. Se faltar o OptiFine, aparece "Baixar OptiFine": abre a página oficial,
  você clica em Download e o launcher importa sozinho da pasta Downloads.
- Perfis disponíveis no seletor de versão:
  VfxClient = Legacy Fabric + todos os recursos do VfxClient (menu, HUD, otimizações) + OptiFine
              no mesmo jogo (via Legacy OptiFabric, que vem no launcher). Para desligar o
              OptiFine: desmarque "OptiFine junto com o VfxClient" na tela Início.
              Sem o arquivo do OptiFine no PC, abre só com o VfxClient.
              Com o OptiFine junto, a tecla de zoom dele (C) é desligada: vale o zoom do VfxClient.
  OptiFine  = Minecraft + OptiFine, sem os recursos do VfxClient;
  Forge     = Forge 1.8.9 (já vem dentro do launcher) para os seus mods, sem os recursos do VfxClient.
  Cada loader tem a própria pasta de jogo (mods separados).
- Forge: o instalador oficial do Forge 1.8.9 vem dentro do launcher e é instalado sozinho
  (em segundo plano) quando o launcher abre. Funciona sem internet depois do primeiro jogo.
- OptiFine: o instalador gerado no SEU PC (build-installer.ps1) já leva o OptiFine junto, se o
  jar estiver em installer\local\ ou na Área de Trabalho; ele vai para a pasta optifine\ do
  VfxClient instalado e o launcher importa sozinho. Esse instalador é só para o grupo: NÃO
  publique no GitHub (a licença do OptiFine proíbe distribuição pública). A release da CI
  (tag no GitHub) sai sem OptiFine. Sem ele, o launcher procura um OptiFine 1.8.9 na Área de
  Trabalho, em Downloads e no .minecraft e importa. Se não achar:
  "Baixar no site oficial", salve o arquivo na Área de Trabalho ou em Downloads (ou use
  "Selecionar OptiFine..."). Pelo terminal:
  VfxClient.exe --cli import-optifine C:\caminho\OptiFine_1.8.9_HD_U_M5.jar
- Forge + OptiFine: no loader Forge, marque "Usar o OptiFine junto com o Forge" (ele vai como mod).
- "Abrir pasta de mods" (loader Forge) abre a pasta onde você coloca os seus mods do Forge.

Conta e skin
- Offline: Conta > digite o nick > Adicionar.
- Skin offline: escolha o PNG (64x64). Inicie o jogo e aperte F5: a skin aparece em você.
- Microsoft: veja a seção 8. Depois do login, "Escolher skin" envia a skin para a conta
  oficial e "Capa" troca a capa (se a conta tiver capas).

No jogo (Right Shift)
- Geral > Menu: "Opções no menu" Simples/Completo (mostra as opções avançadas).
- Telas do jogo (v0.13), todas com as letras Montserrat (títulos e botões) e Inter (textos):
  - Tela inicial: logo grande, UM JOGADOR (roxo), MULTIJOGADOR, ícones no topo (opções, menu
    do VfxClient, pacotes de textura, sair) e idioma embaixo.
  - ESC no jogo: menu de pausa com o mundo desfocado (Visual > Desfoque nos menus), botões
    Voltar, Menu do VfxClient, Opções, Editar HUD, Conquistas, Estatísticas e Desconectar, e
    etiquetas com servidor, ping, jogadores e tempo de sessão.
  - Multijogador: cartões com ping colorido e barras, estrela para favoritar, abas Meus /
    Favoritos / LAN, busca (é só digitar) e duplo clique para entrar.
  - Opções, Vídeo, Controles e as outras telas do jogo (inclusive as do OptiFine): botões e
    sliders planos, fundo escuro no lugar da terra.
  Para voltar às telas originais: Geral > Telas do VfxClient (desligar).- Utilidades > Texto automático: até 6 atalhos (tecla + mensagem ou comando, ex.: "gg", "/l").
- Chat: anti-spam (esconde a mesma mensagem repetida em 3 s), palavras bloqueadas e
  Ctrl + clique numa mensagem para copiar.
- Tab: cabeça dos jogadores também em servidores offline. Placar: "Tamanho (compacto)".
- Launcher > Prints: galeria dos prints (F2); clique abre a imagem.
- Menu (v0.12): contorno verde = ligado, vermelho = desligado. Toda opção de módulo tem
  "Tecla para ligar/desligar"; ao usar a tecla aparece o aviso LIGADO/DESLIGADO na tela.
- Novos: HUD > Contador de blocos; Visual > Hitbox, Cor das partículas, FOV, Item na mão;
  Utilidades > Tooltips com rolagem (rodinha no inventário, Shift = para os lados), Barra de itens.
  CPS com formato [12 CPS]; Teclas com rótulo LMB/RMB; Efeitos com estilo Painel.
- Launcher: ao abrir o jogo ele fica na bandeja do Windows (ícone perto do relógio);
  clique para abrir, ou botão direito > Sair do launcher. Volta sozinho quando o jogo fecha.
- Menu: cartões com contorno (contorno branco = ligado). Clique liga/desliga; a engrenagem
  (ou botão direito) abre as opções. Digite com o menu aberto para buscar um módulo.
- Utilidades > Mira: prévia ao vivo nas opções (sobre céu e fundo escuro, 2x e tamanho real).
- Geral > Estilo da HUD: modo Compacto/Avançado, cor do texto, cor principal (valores em
  destaque), cor secundária mais escura (relógio, servidor, tempo de jogo), fundo (padrão preto
  45%), cantos 0-10 px, espaço interno, atualização do texto (cache).
- Editor de HUD (/vfx hud): o "X" no canto do elemento tira ele da tela; arraste para mover; arraste a alça roxa no canto inferior direito
  do elemento (ou use a rodinha do mouse em cima dele) para mudar o tamanho (0,5x a 2x).
- Geral > Layouts da HUD: Minimal, PvP, Survival, Content Creator, Competitivo > Aplicar.
  Instalação nova já começa no PvP. Depois ajuste no editor de HUD (/vfx hud): cada elemento
  gruda no canto/borda mais próximo e fica no lugar ao mudar o tamanho da janela.
- Cada elemento da HUD: opção avançada "Cores próprias" (texto e fundo só dele).
- HUD: FPS verde/amarelo/vermelho (>=120, 60-119, <60); ping colorido pela conexão; CPS
  esquerdo, direito, os dois ou soma, último segundo ou média de 5 s; coordenadas com bioma e
  conversão Nether/Overworld; armadura com barra e cor; efeitos com ícone e cor do efeito;
  relógio com segundos; Servidor; Tempo de jogo (sessão, hoje, total).
- Utilidades: ping em número na Tab; chat guarda até 1000 linhas; Auto GG (desligado,
  configure as frases e a mensagem); Prints: F2 também copia a imagem (cole com Ctrl+V).
- Visual: Freelook (desligado; Alt esquerdo; ALGUNS SERVIDORES PROÍBEM, veja as regras),
  Motion blur e Saturação de cor (desligados; usam efeitos do próprio Minecraft e precisam de
  "Usar FBOs" ligado nas opções de vídeo).
- Desempenho > FPS dinâmico: limita o FPS sem foco e depois de alguns minutos parado (AFK).
- Geral > Perfis de config: "Copiar" exporta todas as opções em JSON; "Colar" importa.
- Geral > Perfis de config: crie "PvP", troque, apague. Cada perfil guarda tudo.
- Cores: qualquer opção de cor abre o seletor (sliders R/G/B/A, HEX, paleta, prévia).
- Valores: clique no número de um slider (ou botão direito) para digitar.
- HUD > Teclas: estilos, cores, teclas individuais, tamanho, espaço, alinhamento, com
  prévia ao vivo à direita.
- Desempenho > Preset de FPS: Baixo/Equilibrado/Alto, Diagnóstico do PC, otimização
  automática (desce o preset se o FPS ficar abaixo da meta por 15 s).
- Desempenho > Opções gráficas: as opções de gráficos do Minecraft num lugar só.
- Comandos: /vfx, /vfx menu, /vfx hud, /vfx reset.


8. LOGIN MICROSOFT (configuração única)
---------------------------------------
O login oficial exige um aplicativo registrado no Azure (grátis):

1. Entre em https://portal.azure.com com uma conta Microsoft.
2. Microsoft Entra ID > Registros de aplicativo > Novo registro.
   - Nome: VfxClient
   - Tipos de conta: "Somente contas pessoais da Microsoft"
     (ou "Contas em qualquer diretório organizacional e contas pessoais")
   - URI de redirecionamento: deixe vazio
3. Copie o "ID do aplicativo (cliente)".
4. Em Autenticação, ative "Permitir fluxos de cliente público" e salve.
5. No launcher: Configurações > Login Microsoft > cole o Client ID.

LIMITAÇÃO: a Mojang exige aprovação para apps novos usarem a API do Minecraft. Sem
aprovação, o login para na última etapa com a mensagem "A Mojang recusou o login deste
aplicativo". O pedido é feito no formulário de revisão da Microsoft/Mojang
(procure por "Minecraft Services API app review" / aka.ms/mce-reviewappid). Enquanto
não aprovam, use contas offline (servidores não-premium).


9. LIMITAÇÕES E ALTERNATIVAS LOCAIS
-----------------------------------
- Login Microsoft: depende do Client ID e da aprovação acima. Alternativa: conta offline.
- Skin para conta offline: aplicada localmente (só você vê) até existir o servidor de
  contas/skins do VfxClient.
- Capas: só as oficiais de contas Microsoft. Capas próprias virão com o servidor de contas.
- Versões: o launcher abre qualquer versão oficial; os recursos do VfxClient existem só
  no perfil 1.8.9.
- Sem internet: se tudo já foi baixado uma vez, o launcher abre o jogo com os arquivos
  salvos (lista de versões, Legacy Fabric e Java ficam em cache).
- OptiFine: não roda junto com o VfxClient (Legacy Fabric) e a licença não permite
  distribuí-lo. Por isso ele é um loader separado no launcher, com o arquivo baixado pelo
  próprio jogador. As otimizações do loader VfxClient são implementações nossas.
